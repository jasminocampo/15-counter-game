15 Counter Game - Vintage Purple Edition

HOW TO PLAY:
1. Open index.html in a web browser.
2. Click Take 1, Take 2, or Take 3.
3. The computer takes its turn automatically.
4. Whoever takes the last counter wins.
5. Click Play Again to restart.

FILES:
- index.html: game page
- style.css: design
- script.js: game logic

Internet is only needed for the optional Google Fonts styling. The game itself works offline.
